# Пульт управления на ESP32-C3 SuperMini

Отчёт: что за устройство, из чего состоит, как подключить и что докупить.
Пульт — отдельная коробочка в руке: экран, 6 кнопок, связь с монтировкой
без провода.

Соседние документы: [control-interfaces.md](control-interfaces.md) — зачем
отдельный пульт, протокол LX200 и связь ESP-NOW (раздел 2),
[esp32-pins.md](esp32-pins.md) — пины основной платы, [todo.md](todo.md).

## 1. Что умеет пульт

| Функция | Как |
|---|---|
| двигать оси N / S / E / W | пока кнопка нажата, ось едет; отпустил — стоп |
| менять скорость ручного движения | кнопка «СКОР»: ведение ×1 → ×8 → ×64 → перекладка (по кругу) |
| показывать состояние | координаты RA/DEC, ведение вкл/выкл, скорость, авария, заряд, связь |
| меню | кнопка «OK»: вкл/выкл ведение, парковка, яркость экрана |
| связь с монтировкой | **ESP-NOW** — напрямую между ESP32, без роутера и без провода |
| язык команд | **LX200**: `:Mn#` поехать на север, `:Qn#` стоп, `:GR#` где RA? — тот же, что у Stellarium |

**Защита от потери связи.** Пульт опрашивает монтировку раз в 0.5–1 с.
Если ответа нет дольше ~1 с, пульт пишет «нет связи», а монтировка сама
останавливает движение, начатое с пульта. Иначе при пропаже связи посреди
нажатия ось уедет до упора. Подробнее — [control-interfaces.md, 2.4](control-interfaces.md#24-на-каком-языке-говорить-пульту).

## 2. Из чего состоит

```
                       ┌──────────────────────────┐
   аккумулятор ──► TP4056 ──► выключатель ──► 5V  │
   Li-ion 3.7 В   (зарядка    │              │    │
                   по USB-C)  │   ESP32-C3   │3V3 ├──► OLED (VCC)
                              │   SuperMini  │    │
                              │          SDA ├────┼──► OLED (SDA)
                              │          SCL ├────┼──► OLED (SCL)
                              │              │    │
                              │   6 × GPIO   ├────┼──► кнопки ──► GND
                              │   1 × ADC    ├────┼──► делитель от аккумулятора
                              └──────────────┘    │
                                     ))) ESP-NOW  │
                                      │           │
                       └──────────────┼───────────┘
                                      ▼
                         монтировка (ESP32-S3)
```

## 3. Контроллер: ESP32-C3 SuperMini

Выбран: [ESP32-C3 Super Mini на Prom (продавец RadioM, ~145 грн)](https://prom.ua/ua/m4653124674682864941-plata-razrabotki-esp32.html?p=3154811442).

| Что нужно пульту | Что есть у платы | |
|---|---|---|
| ESP-NOW / Wi-Fi / BLE | Wi-Fi 2.4 ГГц, BLE 5.0, ESP-NOW | ✅ |
| дисплей по I2C | I2C на любых двух пинах | ✅ |
| 6 кнопок + I2C + замер батареи = 9 ног | 13 GPIO на краях, ~10 без оговорок | ✅ |
| прошивка и отладка | USB Type-C, USB встроен в сам чип | ✅ |
| размер | ~22 × 18 мм | ✅ |
| среда разработки | ESP-IDF + FreeRTOS, как у основной платы | ✅ |

Чего у платы **нет**: зарядки и разъёма аккумулятора — докупаются отдельно (раздел 6).

**Известная проблема клонов:** у части плат C3 SuperMini слабый Wi-Fi —
антенна слишком близко к другим деталям. Помогает снизить мощность передатчика
в коде (`esp_wifi_set_max_tx_power`). Для ESP-NOW на 2–5 м до монтировки
некритично, но если связь рвётся — начинать с этого.

Брать **2 штуки**: одна запасная или для опытов.

## 4. Дисплей: OLED 1.3"

**1.3" OLED, 128 × 64, I2C, 4 пина, белый.**

| Параметр | Выбор | Почему |
|---|---|---|
| размер | **1.3"** | 0.96" ночью читается с трудом; разрешение то же, 128 × 64 |
| интерфейс | **I2C, 4 пина**: VCC, GND, SCL, SDA | SPI-версия — 6–7 пинов |
| питание | 3.3 В от пина 3V3 платы | модуль работает от 3.3–5 В |
| цвет | **белый** + красная плёнка сверху | красный свет не сбивает ночное зрение; двухцветный жёлто-синий неудобен |
| чип | у 1.3" обычно **SH1106**, у 0.96" — **SSD1306** | разные драйверы в коде ⚠️ смотреть в объявлении |

Яркость (контраст) регулируется командой дисплею — в меню сделать 3–4 уровня.

⚠️ Перед подключением проверить **порядок пинов** на плате дисплея: бывает
`VCC GND SCL SDA` и `GND VCC SCL SDA`. Перепутать питание — сжечь дисплей.

Поиск: `OLED 1.3 128x64 I2C SH1106 white`.

## 5. Кнопки

### 5.1. Раскладка

```
   ┌───────────────────┐
   │   [  OLED 1.3"  ]  │
   │                   │
   │        [N]        │
   │   [W]       [E]   │
   │        [S]        │
   │                   │
   │  [СКОР]    [OK]   │
   └───────────────────┘
```

### 5.2. Какие кнопки

**Тактовые кнопки 12 × 12 мм с колпачками.** Крупные, находятся на ощупь
в темноте и в перчатках. Колпачки разного цвета — различать направления.

Поиск: `tactile switch 12x12x7.3 with cap`.

Для быстрой проверки без пайки подойдёт модуль `5-way navigation button module`
(↑↓←→ + нажатие + SET + RST), но для итогового пульта он мелковат.

### 5.3. Как подключить

Модуль кнопок не нужен — каждая кнопка на свой пин:

```
   C3 SuperMini
  ┌──────────┐
  │   GPIO x ├────┐
  │          │   [кнопка]      × 6, у каждой свой GPIO
  │      GND ├────┘
  └──────────┘
```

- Подтяжка к 3.3 В — **внутренняя**, включается в коде: не нажата → 1, нажата → 0.
- Резисторы не нужны.
- Дребезг контактов гасится в коде: состояние считается изменившимся,
  если держится ~20 мс.

## 6. Питание

### 6.1. Беспроводной пульт (основной вариант)

| Деталь | Зачем |
|---|---|
| аккумулятор Li-ion / LiPo 3.7 В, **1000 мА·ч** (плоский) или 18650 | питание |
| модуль зарядки **TP4056 с защитой**, разъём USB-C | заряжает аккумулятор и отключает его при переразряде/КЗ |
| выключатель (движковый) | чтобы пульт не разряжался в сумке |
| 2 резистора 100 кΩ | делитель для замера заряда (раздел 6.3) |

Как отличить TP4056 **с защитой**: у модуля **6 выводов** (IN+, IN−, B+, B−,
OUT+, OUT−) и рядом с основной микросхемой ещё две маленькие (DW01 и сдвоенный
транзистор). У версии без защиты — 4 вывода. Без защиты аккумулятор можно
убить глубоким разрядом.

Подключение: `B+/B−` → аккумулятор, `OUT+` → выключатель → пин **5V** платы,
`OUT−` → **GND**.

⚠️ Аккумулятор даёт 3.0–4.2 В, а не 5 В. Стабилизатор на плате (5 В → 3.3 В)
работает и от аккумулятора, пока на нём больше ~3.5 В — ниже экран и радио
начнут сбоить. Проверить на своей плате: какой стоит стабилизатор и его
падение напряжения. Пульт должен предупреждать о низком заряде заранее.

⚠️ **Прошивка по USB:** выключать пульт выключателем перед подключением USB
к плате, пока не проверено по схеме, как на ней соединены USB-питание и пин 5V.

### 6.2. Сколько проработает

| Потребитель | Ток (примерно) |
|---|---|
| ESP32-C3 с постоянно включённым радио | 80–100 мА |
| OLED (в основном тёмный экран) | 10–20 мА |
| **итого** | **≈100–120 мА** |

Аккумулятор 1000 мА·ч → **≈8 часов**. На ночь наблюдений хватает. Если
нужно дольше — 18650 (2500–3000 мА·ч) или сон радио между опросами.

### 6.3. Замер заряда

```
  B+ (через выключатель, 3.0–4.2 В)
      │
     [100 кΩ]
      ├──────► GPIO3 (АЦП)   → 1.5–2.1 В
     [100 кΩ]
      │
     GND
```

Делитель пополам: АЦП видит половину напряжения аккумулятора.
Уровни для экрана: 4.2 В — полный, 3.7 В — половина, **3.5 В — «зарядить»**.

### 6.4. Проводной вариант (если не нужен аккумулятор)

Кабель от монтировки: 5 В, GND и UART (TX, RX) вместо ESP-NOW.
Тогда не нужны аккумулятор, TP4056 и делитель. Минус — провод цепляется
за монтировку при вращении ([control-interfaces.md, 2.3](control-interfaces.md#23-связь-пульта-с-монтировкой)).

## 7. Распиновка

Предварительная. Проверить по схеме своей платы ⚠️.

| GPIO | Назначение | Почему здесь |
|---|---|---|
| 0 | кнопка N | |
| 1 | кнопка S | |
| 10 | кнопка E | |
| 7 | кнопка W | |
| 20 | кнопка СКОР | UART0 RX — свободен, если консоль на встроенном USB |
| 21 | кнопка OK | UART0 TX — то же |
| 5 | I2C SDA (OLED) | |
| 6 | I2C SCL (OLED) | |
| 3 | АЦП: заряд аккумулятора | АЦП есть только на GPIO 0–4 |
| 4 | свободен | запас (например, вибромотор или зуммер) |
| **2, 8, 9** | **не занимать** | влияют на режим загрузки; на 8 — светодиод платы, на 9 — кнопка BOOT |

**Про GPIO 20 и 21.** Это пины UART0. Чтобы отдать их кнопкам, консоль
и логи перевести на встроенный USB: в `menuconfig` →
`ESP_CONSOLE_USB_SERIAL_JTAG`. При старте загрузчик всё равно печатает
пару строк в UART0 — кнопкам это не мешает.

## 8. Корпус

Печать PETG или PLA, размер примерно с пульт от телевизора:

- окно под экран + **красная плёнка или красное оргстекло** поверх;
- 6 отверстий под колпачки кнопок, направления — крестом;
- отверстие под USB-C модуля TP4056 (зарядка) и под выключатель;
- доступ к USB-C платы — для прошивки (можно закрыть заглушкой);
- отсек под аккумулятор;
- ремешок или петля — чтобы пульт висел на монтировке, а не лежал на земле.

## 10. План работ

1. ☐ Купить детали (раздел 9).
2. ☐ Проверить плату: прошить «привет» по USB, светодиод на GPIO8.
3. ☐ Подключить OLED, вывести текст. Уточнить чип (SH1106 / SSD1306).
4. ☐ Подключить 6 кнопок на макетке, проверить опрос и антидребезг.
5. ☐ ESP-NOW: пульт ↔ монтировка, обмен строками LX200.
   Перед этим на монтировке должен быть парсер LX200
   ([control-interfaces.md, раздел 6](control-interfaces.md#6-предлагаемый-порядок-работ)).
6. ☐ Опрос состояния, экран «нет связи», остановка при потере связи.
7. ☐ Питание от аккумулятора, замер заряда, проверка времени работы.
8. ☐ Корпус, красный фильтр, итоговая сборка.
