## Этап 0. Открытые вопросы основной платы

- [ ] **Скорости `:RG#` / `:RC#` / `:RM#` / `:RS#` не меняются** (проверка на плате).
  Снять лог после `:RC#` + `:Mw#` и сравнить с ожидаемым ([commands.md](commands.md), раздел 6).
- [ ] Проверить `:Te#` / `:Td#` и правку во время ведения ([commands.md](commands.md), раздел 6).
- [x] Проверка связи с DEC после ожидания питания VS + `tmc_init_step_0(AXIS_DEC)` в начале.
- [ ] Подтяжка 10 кΩ EN → 3.3 В на модуле DEC (железо).
- [ ] Цикл `reset` у RA: ограничение тока блока питания 3 А, напряжение VS на модуле,
  конденсатор 100 мкФ ([tmc-error.md](tmc-error.md), раздел 10.4).
- [ ] Проверить, что первая команда движения после аварии срабатывает (исправление в
  `stepper_emergency_stop`).
- [ ] `ESP_ERR_TMC_VERIFY_FAILED` добавить в `tmc_err_to_name()`, иначе в логе `UNKNOWN ERROR`.

## Этап 2. Пульт управления

Отдельное устройство с кнопками и дисплеем, связь с монтировкой по ESP-NOW,
команды — тот же LX200 ([control-interfaces.md](control-interfaces.md), раздел 2).

### 2.1. Железо пульта

- [x] Микроконтроллер: **ESP32-C3 Super Mini**.
- [x] Дисплей: OLED GME12864-41, 128×64, I2C.
  - [ ] Красный светофильтр или красный дисплей — ночное зрение.
- [x] Кнопки: 8 кнопок через расширитель MCP23017 (I2C) + отдельная кнопка STOP на GPIO10.
  Ведение вкл/выкл — через меню.
- [x] Питание: Li-ion 18650 + TP4056 Type-C с защитой + выключатель.
- [x] Схема подключения: [remote-control/info/wiring.md](../../remote-control/info/wiring.md).

### 2.2. Проект пульта

- [x] Отдельный проект ESP-IDF: `../remote-control`.
- [x] Общий компонент `lx200_format` в `../components`, подключён в оба проекта через
  `EXTRA_COMPONENT_DIRS`. Форматы координат одинаковые с обеих сторон.

### 2.3. Связь ESP-NOW: сторона монтировки

- [x] Канал [lx200_espnow.cpp](../main/lx200/lx200_espnow.cpp) — как `lx200_usb.cpp`: свой `lx200_ctx_t`,
  принятые байты → `lx200_feed()`, ответ — обратно пульту. Запускается в `app_main`.
- [x] Пара «монтировка ↔ пульт»: сопряжение `?PAIR` / `!PAIR` в первые 30 с после
  включения, MAC пульта хранится в NVS ([remote-control/info/pairing.md](../../remote-control/info/pairing.md)).
- [ ] Учесть: если позже монтировка подключится к Wi-Fi роутеру, ESP-NOW должен быть
  на том же радиоканале.

### 2.4. Прошивка пульта

- [x] Кнопки с подавлением дребезга (20 мс, `button_handler`).
- [x] Стрелки → `:Mn#` … при нажатии, `:Qn#` … при отпускании.
- [x] **Пока стрелка нажата — повторять `:M?#` раз в 200 мс** (`arrows`, для защиты из 2.5).
- [x] Кнопка скорости (ENTER на главном экране) → смена скорости стрелок `:R?#`.
- [x] Ведение → `:Te#` / `:Td#` (через меню).
- [x] Дисплей:
  - [x] выбранная скорость, ведение вкл/выкл, зажатые стрелки;
  - [x] связь есть/нет (`Link: OK / LOST`), авария (`Mount: FAULT!`) — из ответа `:GU#`.

### 2.5. Защита от потери связи (основная плата)

- [x] Флаг `keepalive` в `motion_cmd_t`: команду повторяют (пульт ESP-NOW) — [fsm.md](fsm.md), раздел 7.
- [x] Повтор `CMD_MOVE` той же оси в ту же сторону только продлевает движение
  (обновляет время), без пересчёта скорости и лишних логов.
- [x] Нет повтора от пульта дольше 500 мс → автомат сам останавливает ось (как `CMD_STOP`).

### 2.6. Состояние для дисплея пульта

- [x] Команда `:GU#` в формате OnStepX (урезанный): ведение, GoTo, скорость стрелок, авария.
  Сборка и разбор — `lx200_format_status` / `lx200_parse_status` в общем компоненте `lx200_format`.
- [x] Пульт опрашивает её раз в 500 мс (`mount_link`). Нет ответа дольше 1.5 с — «нет связи».

### 2.7. Проверка пульта

- [ ] Стрелки двигают оси, отпускание останавливает.
- [ ] Смена скорости на ходу.
- [ ] Правка во время ведения: отпустил — ведение продолжается.
- [ ] Выключить пульт посреди нажатия → ось сама остановилась за ~0.5 с.
- [ ] Авария драйвера → на дисплее пульта видно.

## Этап 3. Где смотрит телескоп (математика)

Перевод «шаги моторов ↔ координаты неба» ([control-interfaces.md](control-interfaces.md),
раздел 3.4).

- [ ] Текущая позиция оси в шагах — функция в `stepper`.
- [ ] Источник времени: от компьютера (`:SC` / `:SL` / `:SG`), NTP по Wi-Fi или часы RTC.
- [ ] Место: долгота и широта (`:Sg` / `:St`).
- [ ] Модуль математики (например, `main/astro/`): юлианская дата → звёздное время →
  часовой угол → RA; позиция DEC. Проверки на компьютере, как у `lx200_format`.
- [ ] `:GR#` / `:GD#` — текущие координаты; `:U#` — короткий/длинный формат.
- [ ] `:CM#` — синхронизация: «телескоп сейчас смотрит на эту звезду».
- [ ] После `:CM#` включать ведение автоматически.
- [ ] Проверка: Stellarium по USB показывает на карте, куда смотрит телескоп.

## Этап 4. GoTo из Stellarium

- [ ] `:Sr…#` / `:Sd…#` — цель (разбор уже есть в `lx200_format`).
- [ ] `:MS#` — координаты → шаги → `motion_goto()`; ответ `0` или `1текст#`.
- [ ] Сторона монтировки (pier side) и переворот у меридиана.
- [ ] Ограничения: горизонт, меридиан — чтобы труба не ударилась о штатив.
- [ ] `:GVP#` / `:GVN#` — имя и версия (некоторые программы спрашивают при подключении).
- [ ] Проверка: GoTo на звезду из Stellarium, звезда в искателе.
