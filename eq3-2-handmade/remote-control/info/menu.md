# Пульт EQ3-2: экраны, меню и команды LX200

Пульт отправляет монтировке только **команды LX200**. Реальные скорости (во сколько раз быстрее звёздной) задаёт прошивка монтировки ([../mount](../../mount), её `info/commands.md`), а не пульт.

| Параметр | Решение |
|---|---|
| Связь | ESP-NOW (модуль [espnow_link](../main/espnow_link/espnow_link.md)), позже добавится Wi-Fi |
| Язык интерфейса | английский |
| Дисплей | OLED 128×64 (8 строк × 21 символ) |
| Кнопки | STOP, MENU, ENTER, ◄, ►, ▲, ▼ (MCP23017, GPA0–GPA6) |

---

## 1. Кто что знает: пульт и монтировка

| Что | Где хранится | Почему |
|---|---|---|
| **Состояние монтировки**: `IDLE` / `TRACKING` / `GOTO` / `FAULT` | монтировка; на пульте только **копия** у задачи [mount_link](../main/mount_link/mount_link.md) (`mount_link_get_tracking()`) | меняется без пульта: `:Q#`, авария, конец GoTo, Stellarium |
| **Скорость стрелок**: GUIDE / CENTER / FIND / SLEW | пульт (модуль [settings](../main/settings/settings.md)) | главный по скорости — пульт: на экране всегда та скорость, с которой поедешь |
| Яркость экрана | пульт (settings) | это настройка самого пульта |

Состояния монтировки (её `info/fsm.md`):

| Состояние | Что происходит |
|---|---|
| `IDLE` | моторы стоят, ведения нет. Так монтировка стартует |
| `TRACKING` | ось RA ведёт со звёздной скоростью |
| `GOTO` | обе оси едут к цели; по окончании — `TRACKING` |
| `FAULT` | авария драйвера, движение заблокировано; после снятия — `IDLE` |

Типичный порядок:

```
IDLE  ── стрелки (SLEW / FIND / CENTER) ──► навёлся на Полярную
      ── MENU → Tracking → ON  (:Te#) ───► TRACKING
      ── стрелки (GUIDE) ──────────────► подправить ведение
      ── STOP  (:Q#) ──────────────────► IDLE
```

Копию состояния пульт берёт из ответа монтировки на `:GU#` (опрос раз в 500 мс, [mount_link](../main/mount_link/mount_link.md)): ведение, авария, есть ли связь.

## 2. Скорости стрелок

| Команда | На экране | Для чего |
|---|---|---|
| `:RG#` | GUIDE | правка во время ведения (0.5× звёздной) |
| `:RC#` | CENTER | поставить объект в центр окуляра (8×) |
| `:RM#` | FIND | поиск в искателе (64×) |
| `:RS#` | SLEW | перекладка, максимальная скорость |

- После включения пульт стоит на GUIDE, а монтировка — на SLEW.
- Скорость отправляется **при смене** (ENTER на главном экране или пункт Speed) и **ещё раз при каждом нажатии стрелки** (`:R?#` + `:M?#`). Так монтировка всегда едет с той скоростью, что на экране пульта, даже если перезагрузилась или скорость поменял Stellarium.
- Если стрелка уже нажата, монтировка сразу переходит на новую скорость.

## 3. Кнопки и команды

### 3.1. Главный экран (меню закрыто)

| Кнопка | Нажатие | Держу | Отпускание |
|---|---|---|---|
| ▲ | `:R?#` `:Mn#` (север) | `:Mn#` каждые 200 мс | `:Qn#` |
| ▼ | `:R?#` `:Ms#` (юг) | `:Ms#` каждые 200 мс | `:Qs#` |
| ► | `:R?#` `:Me#` (восток) | `:Me#` каждые 200 мс | `:Qe#` |
| ◄ | `:R?#` `:Mw#` (запад) | `:Mw#` каждые 200 мс | `:Qw#` |
| ENTER | следующая скорость по кругу GUIDE → CENTER → FIND → SLEW, сразу `:R?#` | — | — |
| MENU | отпустить зажатые стрелки (`:Q?#`), открыть меню | — | — |
| **STOP** | `:Q#` | — | — |

`:R?#` — текущая скорость стрелок (`:RG#` / `:RC#` / `:RM#` / `:RS#`).

### 3.2. В меню

| Кнопка | Действие |
|---|---|
| ▲ ▼ | вверх / вниз по списку (монтировку не двигают) |
| ► | войти в пункт |
| ◄ | назад; с верхнего уровня — закрыть меню |
| ENTER | выбрать |
| MENU | закрыть меню, вернуться на главный экран |
| **STOP** | `:Q#`, меню остаётся открытым |

### 3.3. STOP

**STOP работает на любом экране и всегда делает одно и то же**: `:Q#`. Монтировка останавливает стрелки, GoTo и ведение и переходит в `IDLE`, поэтому отдельный `:Td#` не нужен. Ведение включается заново пунктом меню **Tracking → ON**.

## 4. Экраны

```
┌─────────────────────┐   ┌─────────────────────┐   ┌─────────────────────┐
│EQ3-2 REMOTE         │   │MENU                 │   │TRACKING             │
│─────────────────────│   │─────────────────────│   │─────────────────────│
│Tracking: ON         │   │> Speed     GUIDE    │   │> * OFF              │
│Speed:    GUIDE      │   │  Tracking  OFF      │   │    ON               │
│Move:     W          │   │  Display   LOW      │   │                     │
│                     │   │  Link      PAIRED   │   │                     │
│ENTER: speed         │   │                     │   │                     │
│MENU:  menu          │   │                     │   │                     │
└─────────────────────┘   └─────────────────────┘   └─────────────────────┘
      главный экран                меню              выбор значения (> курсор,
                                                     * — текущее значение)
```

- `Move:` — зажатые стрелки (`N` `S` `E` `W`), `-` если ни одной.
- Заголовок главного экрана пока постоянный. После ESP-NOW — состояние монтировки (раздел 7).

## 5. Пункты меню

| Пункт | Значения | Где хранится | Команда LX200 |
|---|---|---|---|
| **Speed** | GUIDE / CENTER / FIND / SLEW | `settings` | `:RG#` / `:RC#` / `:RM#` / `:RS#` |
| **Tracking** | OFF / ON | копия состояния монтировки в `mount_link` | `:Td#` / `:Te#` |
| **Link** → Pair / Unpair / Mount | сопряжение с монтировкой | NVS (`espnow_link`) | служебные `?PAIR` / `!PAIR` ([pairing.md](pairing.md)) |
| Display | LOW / MID / HIGH | `settings` | ничего; сразу меняет контраст OLED пульта (`0x08` / `0x7F` / `0xFF`) |

- У `CHOICE` нет указателя на значение: меню читает его через `get()` и меняет через `set()`. **Tracking**: `get` читает копию состояния монтировки, `set` отправляет `:Te#`/`:Td#` задаче `mount_link`. Копия изменилась → экраны получают `SCREEN_MSG_MOUNT_CHANGED` и перерисовываются. Копию меняет ответ монтировки на `:GU#`, поэтому в `FAULT` пункт честно останется OFF.
- **Полушария** в меню нет: это настройка монтировки.

## 6. Как устроено в коде

Каждая часть пульта — отдельная задача FreeRTOS. Задачи не вызывают функции друг друга,
а кладут сообщения в очереди. Подробности — в `.md` в каждой папке `main/`.

```
                    ┌───────────────────────┐
     ISR (INTA) ───►│ task_button_handler 10│   читает MCP23017
                    └───────────┬───────────┘
                                │ SCREEN_MSG_BUTTON во все очереди подписчиков
                 ┌──────────────┴───────────────┐
                 ▼                              ▼
     ┌──────────────────────┐  SHOW   ┌──────────────────┐
     │ task_main_screen   5 │ ──────► │ task_menu      5 │
     │ main_view, arrows    │ ◄────── │ menu_nav, items, │
     │ STOP                 │  SHOW   │ menu_view        │
     └──────────┬───────────┘         └────────┬─────────┘
                │ mount_link_*()               │ set() → mount_link_*()
                └──────────────┬───────────────┘
                               ▼ очередь mount_cmd_t
                    ┌───────────────────────┐
                    │ task_mount_link     7 │──► SCREEN_MSG_MOUNT_CHANGED подписчикам
                    │ копия состояния       │
                    └───────────┬───────────┘
                                │ espnow_link_send(":Me#")
                    ┌───────────▼───────────┐
                    │ task_espnow_link    8 │──► радио ESP-NOW ──► монтировка
                    └───────────────────────┘
```

| Модуль | Задача | Что делает |
|---|---|---|
| [button_handler](../main/button_handler/button_handler.md) | `task_button_handler` (10) | читает MCP23017, рассылает «нажал»/«отпустил» подписчикам |
| [main_screen](../main/main_screen/main_screen.md) | `task_main_screen` (5) | главный экран: стрелки ([arrows](../main/main_screen/arrows.md)), ENTER, STOP, отдаёт экран меню |
| [menu](../main/menu/menu.md) | `task_menu` (5) | меню: навигация, пункты, отрисовка; возвращает экран |
| [mount_link](../main/mount_link/mount_link.md) | `task_mount_link` (7) | единственная точка отправки команд, копия состояния монтировки |
| [espnow_link](../main/espnow_link/espnow_link.md) | `task_espnow_link` (8) | радио: отправка и приём пакетов, LX200 не знает |
| [screen_msg](../main/screen_msg/screen_msg.md) | — | тип сообщения в очередь экрана |
| [settings](../main/settings/settings.md) | — | скорость стрелок и яркость (`std::atomic`) |
| [lx200_commands](../main/lx200_commands/lx200_commands.md) | — | сборка строк `:...#` |

**Экран у одной задачи.** Рисует только та задача-экран, у которой `active = true`.
Экран передаётся сообщением `SCREEN_MSG_SHOW`: main_screen → menu при MENU, menu → обратно при закрытии.

**Порядок запуска** (`app_main`): `espnow_link_init` → `mount_link_init` → `menu_init` → `main_screen_init` → `init_btn_handler`.
Сначала создаются те, кому шлют сообщения, а подписки делаются в `*_init()` до старта кнопок.

## 7. Защита от потери связи (ESP-NOW)

Схема «нажал → `:Me#`, отпустил → `:Qe#`» опасна по радио:

```
Нажал ►  ── :Me# ──►  монтировка поехала на SLEW
Отпустил ── :Qe# ──X  пакет потерялся
                      монтировка едет дальше
```

| Где | Что делать | Сделано |
|---|---|---|
| Пульт | пока стрелка зажата, повторять `:M?#` каждые ~200 мс | ✅ `arrows_repeat()` |
| Монтировка | если повтор не пришёл за ~500 мс, остановить ось самостоятельно | ✅ (её `fsm.md`, раздел 7) |
| Пульт | проверять подтверждение доставки ESP-NOW и повторять `:Q?#` / `:Q#` при неудаче | ☐ |

## 8. Что нужно на стороне прошивки монтировки

| Что | Зачем | Есть |
|---|---|---|
| `:RG#` `:RC#` `:RM#` `:RS#` | скорости стрелок | ✅ |
| `:Mn#` `:Ms#` `:Me#` `:Mw#`, `:Qn#` `:Qs#` `:Qe#` `:Qw#`, `:Q#` | движение и остановка | ✅ |
| `:Te#` / `:Td#` | ведение (расширение OnStep) | ✅ |
| канал ESP-NOW, ответ — тому, кто спросил | связь с пультом | ☐ |
| при старте сообщить пульту своё состояние | начальная синхронизация | ☐ |
| команда состояния: `IDLE`/`TRACKING`/`GOTO`/`FAULT` + скорость | экран пульта, NO LINK | ☐ формат не выбран |
| сторож ~500 мс на повтор `:M?#` | остановка при потере связи | ✅ |
| `:TQ#` `:TL#` `:TS#` | скорость ведения (звёздная / лунная / солнечная) | ☐ из пульта убрано, пока нет на монтировке |

### После ESP-NOW

1. ✅ **Транспорт** — `espnow_link`: команды уходят по ESP-NOW; MAC монтировки — сопряжением из меню (Link → Pair, [pairing.md](pairing.md)). На монтировке — `lx200_espnow` (тот же канал, ответ `!PAIR`).
2. ✅ **Начальная синхронизация** (закрыта опросом из п. 3: первый ответ `:GU#` приходит через ≤ 0.5 с) — монтировка при старте присылает своё состояние, `task_mount_link` записывает его в копию состояния. Скорость стрелок пульт не берёт, а сам отправляет свою (главный по скорости — пульт).
3. ✅ **Опрос состояния** раз в 500 мс: `:GU#` в формате OnStepX (`lx200_format_status` / `lx200_parse_status` в общем компоненте).
4. ✅ **Копия состояния** в `mount_link`: `connected`, `tracking`, `fault`, время последнего ответа. `GOTO` — когда в монтировке появится GoTo.
5. ✅ **Приём ответов** — колбэк приёма ESP-NOW не меняет копию сам, а кладёт ответ в очередь `task_mount_link`: копию по-прежнему пишет только эта задача.
6. ✅ **Ответ на `:Te#`/`:Td#`** — копию пульт больше не меняет «заранее»: после команды сразу спрашивает `:GU#`, ответ `1`/`0` пропускает.
7. ✅ **Нет связи** — нет ответа дольше 1.5 с: строка `Link: LOST` на главном экране, `Tracking: ?`; авария — `Mount: FAULT!`.
8. **Заголовок главного экрана** — состояние монтировки: `IDLE` / `TRACKING` / `GOTO` / `FAULT` / `NO LINK`.
9. **Стрелки при `FAULT` / NO LINK** — решить: блокировать на пульте и показывать причину.
10. **Подтверждение доставки** ESP-NOW: повторять `:Q?#` / `:Q#`, если пакет не дошёл.
11. ✅ **Перерисовка по ответу монтировки** — `SCREEN_MSG_MOUNT_CHANGED` уже есть, ответы ESP-NOW будут вызывать его так же.

### Не связано с ESP-NOW

12. ✅ **Display** — меняет контраст OLED (`oled_set_contrast`). Если LOW ночью всё ещё ярко — уменьшать предзаряд `0xD9` и VCOMH `0xDB`.
13. **Заряд аккумулятора** в углу экрана ([wiring.md](wiring.md), раздел 3.4).
14. **Скорость ведения** (`:TQ#` `:TL#` `:TS#`) — вернуть пункт Rate, когда монтировка научится этим командам.
15. **Две стрелки одной оси** (▲ и ▼ одновременно): монтировка останавливает по оси, поэтому отпускание одной остановит ось, а повтор другой снова её запустит. Решить, нужно ли что-то с этим делать.
