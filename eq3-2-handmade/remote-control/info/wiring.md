# Пульт EQ3-2: схема подключения

Плата: **ESP32-C3 Super Mini**
Дисплей: **OLED GME12864-41** (I²C, 128×64)
Расширитель кнопок: **MCP23017** (I²C, 16 линий)
Питание: **Li-ion 18650** + модуль зарядки **TP4056 Type-C с защитой**

---

## 1. Общая структура

```
 ┌────────────┐     ┌────────┐     ┌──────┐     ┌─────────────────┐
 │ 18650      ├────►│ TP4056 ├────►│ ВЫКЛ ├──┬─►│ SS14 ──► 5V     │
 │ 3.0–4.2 В  │     │ защита │     └──────┘  │  │                 │
 └────────────┘     └───▲────┘               │  │ ESP32-C3        │
                        │                    │  │ Super Mini      │
                  USB-C (зарядка)            │  │                 │
                                             └─►│ GPIO4  (АЦП)    │
                                                │                 │
                         ┌──────────────────────┤ 3V3 (выход)     │
                         │                      │                 │
                ┌────────┴────────┐             │ GPIO6  SDA ─────┼──┐
                │                 │             │ GPIO7  SCL ─────┼──┤ шина I²C
           ┌────▼────┐      ┌─────▼─────┐       │ GPIO3  INT ◄────┼──┤
           │ OLED    │◄─I²C─┤ MCP23017  │◄─INT──┤                 │  │
           │ 0x3C    │      │ 0x20      │       │ GPIO10 STOP ◄───┼──┼── кнопка STOP
           └─────────┘      └─────┬─────┘       └─────────────────┘  │
                                  │                                  │
                             8 кнопок
```

## 2. Назначение пинов ESP32-C3 Super Mini

| Пин | Назначение | Примечание |
|---|---|---|
| **5V** | вход питания (от аккумулятора через диод) | вход встроенного стабилизатора 3.3 В |
| **GND** | общий минус | |
| **3V3** | выход 3.3 В → OLED, MCP23017 | |
| **GPIO6** | I²C SDA | |
| **GPIO7** | I²C SCL | |
| **GPIO3** | прерывание от MCP23017 (INTA) | «какую-то кнопку нажали» |
| **GPIO4** | АЦП: напряжение аккумулятора | ADC1_CH4, через делитель 1:2 |
| **GPIO10** | кнопка STOP | напрямую, без MCP23017, для надёжности |
| GPIO0, 1, 2, 5 | свободны | 2 — strapping-пин, осторожно |
| GPIO20, 21 | свободны | UART0 RX/TX, к Type-C не подключены |
| GPIO8 | **не использовать** | синий светодиод на плате, strapping-пин |
| GPIO9 | кнопка BOOT на плате | можно читать как дополнительную кнопку |
| GPIO18, 19 | **не использовать** | USB (Type-C): прошивка и логи |

## 3. Питание

### 3.1. Схема

```
                    ┌──────────── TP4056 (Type-C, с защитой) ────────────┐
   USB-C ──────────►│ IN+ / IN−                                          │
   (зарядка)        │                                                    │
                    │   B+ ──────┐                       OUT+ ───┐       │
                    │   B− ────┐ │                       OUT− ─┐ │       │
                    └──────────┼─┼───────────────────────────────┼─┼─────┘
                               │ │                               │ │
                       ┌───────┘ └──────┐                        │ │
                       │   ┌─────────┐  │                        │ │
                       └───┤− 18650 +├──┘                        │ │
                           └─────────┘                           │ │
                                                                 │ │
   ┌─────────────────────────── GND (общий минус) ───────────────┘ │
   │                                                               │
   │                                    ВЫКЛЮЧАТЕЛЬ                │
   │                   ┌──────────────────o/ o─────────────────────┘
   │                   │
   │                   ├──── R1 100k ──┬──────────────► GPIO4 (АЦП)
   │                   │               │
   │                   │             R2 100k   C1 100nF
   │                   │               │         │
   │   ┌───────────────┼───────────────┴─────────┘
   │   │               │
   │   │               ▼  D1 SS14 (полоска → к Super Mini)
   │   │              ─┬─
   │   │              ─┴─
   │   │               │
   │   │               │   ┌─────── ESP32-C3 Super Mini ───────┐
   │   │               └──►│ 5V                                │
   │   │                   │        [стабилизатор 3.3 В]       │
   ├───┴──────────────────►│ GND                               │
   │                       │ 3V3 ──┬───────────────────────────│
   │                       └───────┼───────────────────────────┘
   │                               │
   │                               ├── C2 10µF ── GND
   │                               ├──► OLED VCC
    │                               └──► MCP23017 VDD
   │
   └──► OLED GND, MCP23017 VSS (все минусы вместе)
```

### 3.2. Правила

| Что | Правило |
|---|---|
| B+ / B− на TP4056 | **только аккумулятор** |
| OUT+ / OUT− на TP4056 | **только нагрузка** (иначе защита не работает) |
| Диод D1 SS14 | полоска на корпусе → в сторону пина 5V Super Mini |
| Делитель R1/R2 | после выключателя, но **до** диода, чтобы мерить настоящее напряжение аккумулятора |
| C1 100 нФ | вплотную к пину GPIO4 |
| Зарядка | при выключенном пульте; не заряжать ниже 0 °C |

### 3.3. Зачем диод

Пин 5V на Super Mini соединён с USB-разъёмом напрямую. При прошивке 5 В от компьютера без диода пошли бы в аккумулятор. Диод пропускает ток только от аккумулятора к плате.

### 3.4. Напряжения

| Аккумулятор | Пин АЦП (GPIO4) | После диода (пин 5V) | Пин 3V3 | Состояние |
|---|---|---|---|---|
| 4.20 В | 2.10 В | 3.90 В | 3.30 В | полный |
| 3.90 В | 1.95 В | 3.60 В | 3.30 В | ~75% |
| 3.70 В | 1.85 В | 3.40 В | 3.30 В | ~45% |
| 3.50 В | 1.75 В | 3.20 В | ~3.1 В | ~15%, предупреждение «Low battery» |
| 3.30 В | 1.65 В | 3.00 В | ~2.9 В | ~3%, уйти в deep sleep |
| 2.50 В | — | — | — | защита TP4056 отключила выход |

## 4. Шина I²C

```
 ESP32-C3                 OLED GME12864-41           MCP23017
 ────────                 ────────────────           ────────
 3V3 ──────┬──────────────► VCC                ┌──► VDD  (9)
           │                                   │
           ├───────────────────────────────────┘
           │
           ├── R3 4.7k ──┐  (если на OLED-модуле нет своих подтяжек)
           ├── R4 4.7k ──┼──┐
           │             │  │
 GPIO6 ────┼─────────────┴──┼─► SDA ──────────────► SDA  (13)
 GPIO7 ────┼────────────────┴─► SCL ──────────────► SCL  (12)
           │
 GND ──────┴──────────────────► GND ──────────────► VSS  (10)
```

| Устройство | Адрес I²C |
|---|---|
| OLED | 0x3C |
| MCP23017 (A0=A1=A2=GND) | 0x20 |

- Порядок выводов OLED (GND/VCC/SCL/SDA или VCC/GND/…) бывает разным, **сверяйтесь с подписями на модуле**.
- На большинстве OLED-модулей уже стоят подтяжки 4.7–10 кОм. Если они есть, R3/R4 не нужны.

## 5. MCP23017

### 5.1. Выводы (корпус DIP-28, вид сверху)

```
                ┌────╮╭────┐
   GPB0  ◄─  1  │    ╰╯    │ 28  ─► GPA7  ✗ только выход
   GPB1  ◄─  2  │          │ 27  ─► GPA6
   GPB2  ◄─  3  │          │ 26  ─► GPA5
   GPB3  ◄─  4  │          │ 25  ─► GPA4
   GPB4  ◄─  5  │          │ 24  ─► GPA3
   GPB5  ◄─  6  │ MCP23017 │ 23  ─► GPA2
   GPB6  ◄─  7  │          │ 22  ─► GPA1
   GPB7  ◄─  8  │ ✗ выход  │ 21  ─► GPA0
   VDD   ──  9  │          │ 20  ─► INTA  ──► GPIO3 ESP32
   VSS   ── 10  │          │ 19  ─  INTB  (не подключать)
   NC    ── 11  │          │ 18  ─  RESET ──► 10k ──► 3V3
   SCL   ── 12  │          │ 17  ─  A2    ──► GND
   SDA   ── 13  │          │ 16  ─  A1    ──► GND
   NC    ── 14  │          │ 15  ─  A0    ──► GND
                └──────────┘
```

### 5.2. Подключение

| Вывод | Куда | Зачем |
|---|---|---|
| 9 VDD | 3V3 | питание |
| 10 VSS | GND | земля |
| 12 SCL | GPIO7 | I²C |
| 13 SDA | GPIO6 | I²C |
| 15, 16, 17 A0/A1/A2 | GND | адрес 0x20 |
| 18 RESET | через R5 10 кОм на 3V3 | **обязательно**, иначе случайные сбросы |
| 20 INTA | GPIO3 | сигнал «нажата кнопка» |
| 19 INTB | не подключать | в прошивке включить MIRROR, чтобы INTA срабатывал от обоих портов |
| C3 100 нФ | между 9 и 10, **вплотную к чипу** | гасит помехи по питанию |

> **GPA7 и GPB7 не использовать для кнопок.** По актуальному даташиту Microchip эти два вывода работают только как выходы.
> Для кнопок доступны 14 линий: GPA0–GPA6 и GPB0–GPB6.

## 6. Кнопки

Каждая кнопка ставится **между выводом и GND**. Подтяжка к 3.3 В внутренняя, её включают в прошивке (у MCP23017 регистр GPPU, ~100 кОм; у ESP32 — `GPIO_PULLUP_ENABLE`). Отпущенная кнопка читается как 1, нажатая как 0.

```
  вывод MCP23017 ──┤ кнопка ├── GND
```

| Кнопка | Куда | Вывод MCP23017 (номер ножки) |
|---|---|---|
| ▲ DEC+ (вверх) | MCP23017 | GPA0 (21) |
| ▼ DEC− (вниз) | MCP23017 | GPA1 (22) |
| ◄ RA− (влево) | MCP23017 | GPA2 (23) |
| ► RA+ (вправо) | MCP23017 | GPA3 (24) |
| SPEED+ | MCP23017 | GPA4 (25) |
| SPEED− | MCP23017 | GPA5 (26) |
| ENTER | MCP23017 | GPA6 (27) |
| ESC / MENU | MCP23017 | GPB0 (1) |
| резерв (6 шт.) | MCP23017 | GPB1–GPB6 (2–7) |
| **STOP** | **ESP32 GPIO10** напрямую | — |

STOP подключена напрямую к ESP32: она должна срабатывать, даже если шина I²C зависла.

## 7. Перечень элементов обвязки

| Обозначение | Номинал | Где стоит |
|---|---|---|
| D1 | SS14 (или 1N5819) | между выключателем и пином 5V |
| R1, R2 | 100 кОм | делитель аккумулятора → GPIO4 |
| C1 | 100 нФ | на GPIO4 |
| C2 | 10 мкФ | на линии 3V3 |
| C3 | 100 нФ | у выводов питания MCP23017 |
| R3, R4 | 4.7 кОм | подтяжки SDA/SCL (если их нет на OLED) |
| R5 | 10 кОм | RESET MCP23017 → 3V3 |
| SW1 | движковый / тумблер | плюс питания после OUT+ |

## 8. Первое включение (проверка мультиметром)

Проверять **до установки** Super Mini, OLED и MCP23017:

1. Вставить аккумулятор и измерить B+/B−. Должно быть 3.0–4.2 В.
2. Измерить OUT+/OUT−. Должно быть то же напряжение. Если 0 В, подключить USB-C к TP4056 на секунду, чтобы разбудить защиту.
3. Включить SW1 и измерить напряжение после D1. Должно быть примерно на 0.3 В меньше, чем на аккумуляторе.
4. Измерить точку GPIO4. Должна быть половина напряжения аккумулятора.
5. Проверить полярность на месте пинов 5V/GND Super Mini.
6. Установить Super Mini и измерить пин 3V3. Должно быть 3.3 В.
7. Установить OLED и MCP23017. Сканером I²C проверить, что видны адреса 0x3C и 0x20.
