# mount_link — задача связи с монтировкой

## Какую задачу решает

Пульт отправляет монтировке команды LX200 и хранит копию её состояния. Этим занимается
**одна задача** `task_mount_link`:

- команды из разных задач (main_screen, menu) идут через одну очередь и уходят по порядку;
- отправка по радио идёт через [espnow_link](../espnow_link/espnow_link.md) только отсюда;
- копию состояния пишет только эта задача, а читают все.

```
main_screen ─┐ mount_link_move() ...                       ┌─► лог "TX :Mw#" + espnow_link_send() ─► радио
menu ────────┴──────────► очередь ──► task_mount_link ─────┤      (+ раз в 500 мс :GU#, без лога)
espnow_link ── ответы монтировки ──► rx_queue ──►┘          └─► SCREEN_MSG_MOUNT_CHANGED подписчикам
```

## Файлы

| Файл | Что внутри |
|---|---|
| `mount_link.h` | API: init, подписка, чтение копии, команды |
| `mount_link.cpp` | `mount_cmd_t`, очередь, задача, сборка и отправка, копия состояния |

## Функции-команды

Функции **не отправляют сами**: они кладут `mount_cmd_t` в очередь задачи (ждут
не дольше 50 мс) и сразу возвращаются.

| Функция | Команда | Кто вызывает |
|---|---|---|
| `mount_link_rate(rate)` | `:RG#` `:RC#` `:RM#` `:RS#` | ENTER, пункт Speed, перед каждым нажатием стрелки |
| `mount_link_move(dir)` | `:Mn#` `:Ms#` `:Me#` `:Mw#` | стрелка нажата и повтор каждые 200 мс |
| `mount_link_stop_dir(dir)` | `:Qn#` `:Qs#` `:Qe#` `:Qw#` | стрелка отпущена |
| `mount_link_tracking(on)` | `:Te#` / `:Td#` | пункт Tracking |
| `mount_link_stop_all()` | `:Q#` | STOP |

## Копия состояния монтировки

Пульт **не угадывает** состояние по своим командам: раз в 500 мс задача спрашивает `:GU#`
и берёт состояние из ответа (формат OnStepX, разбор — `lx200_parse_status` в общем
компоненте `lx200_format`).

| Функция | Что возвращает |
|---|---|
| `mount_link_is_connected()` | монтировка отвечает: ответ на `:GU#` был не позже 1.5 с назад |
| `mount_link_get_tracking()` | 0 — ведение выключено, 1 — включено (без связи — последнее известное) |
| `mount_link_is_fault()` | авария драйвера: движение заблокировано |

Хранится в `std::atomic`: пишет только задача, читать можно откуда угодно.

| Пришло от монтировки | Что делает задача |
|---|---|
| `NpEo220#` (ответ `:GU#`) | обновить копию, запомнить время ответа |
| `1` / `0` (ответ `:Te#` / `:Td#`) | пропустить: состояние придёт в следующем `:GU#` |
| нет ответа `:GU#` дольше 1.5 с | `connected = false` — «нет связи» |

После `:Te#`, `:Td#` и `:Q#` задача спрашивает `:GU#` сразу, не дожидаясь 500 мс:
экран показывает новое состояние без задержки.

Когда копия изменилась, задача отправляет `SCREEN_MSG_MOUNT_CHANGED` всем подписчикам
(`mount_link_subscribe`), и активный экран перерисовывается.

## Задача

| Параметр | Значение |
|---|---|
| Очереди | 16 × `mount_cmd_t` (команды), 4 × `espnow_packet_t` (ответы) |
| Цикл | ждёт команду до 20 мс, затем разбирает ответы и при необходимости спрашивает `:GU#` |
| Стек | 4096 байт |
| Приоритет | 7: выше экранов (5), команда уходит сразу, как её положили |

## Порядок запуска

`mount_link_init()` — после `espnow_link_init()` (через него уходят команды) и до экранов:
экраны подписываются на неё в своих `*_init()`.
