# lx200_commands — сборка команд LX200

## Какую задачу решает

Монтировка понимает команды LX200: строки вида `:Me#`. Модуль собирает такие
строки из понятных значений (направление, скорость), чтобы остальной код
не склеивал символы вручную:

```cpp
char cmd[LX200_CMD_BUF_SIZE];
size_t len = lx200_cmd_move(LX200_DIR_E, cmd, sizeof(cmd));   // cmd = ":Me#", len = 4
```

Модуль только **собирает** строки, а отправляет их [mount_link](../mount_link/mount_link.md).

## Почему здесь, а не в `components/`

Команды собирает только пульт: монтировка их разбирает. Общее для обоих —
буквы направлений и скоростей — уже лежит в компоненте `lx200_format`
(`lx200_dir_to_char`, `lx200_rate_to_char`), и модуль пользуется им.

## Файлы

| Файл | Что внутри |
|---|---|
| `lx200_commands.h` | функции и `LX200_CMD_BUF_SIZE` (8 байт — хватает на любую команду) |
| `lx200_commands.cpp` | `build()` — `':' + тело + '#'`, `build_letter()` — команда из двух букв |

## Функции

| Функция | Команда |
|---|---|
| `lx200_cmd_rate(rate, ...)` | `:RG#` `:RC#` `:RM#` `:RS#` |
| `lx200_cmd_move(dir, ...)` | `:Mn#` `:Ms#` `:Me#` `:Mw#` |
| `lx200_cmd_stop_dir(dir, ...)` | `:Qn#` `:Qs#` `:Qe#` `:Qw#` |
| `lx200_cmd_stop_all(...)` | `:Q#` |
| `lx200_cmd_tracking_on(...)` | `:Te#` |
| `lx200_cmd_tracking_off(...)` | `:Td#` |

Все функции возвращают длину строки, или **0**, если буфер мал или значение неизвестно.

## Правило

Здесь только команды, которые **понимает монтировка** (её `info/commands.md`).
`:TQ#` `:TL#` `:TS#` (скорость ведения) и запрос состояния добавятся, когда их
сделают на монтировке.
