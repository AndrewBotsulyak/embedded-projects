# arrows — ручное движение стрелками

## Какую задачу решает

Стрелка на пульте работает как «нажал и держу»: пока кнопка зажата, ось едет.
По радио это опасно: если пакет «отпустил» потеряется, ось поедет до упора.
Модуль помнит, какие стрелки зажаты, и сам отправляет все нужные команды:

```
нажал ►     :RG#  :Me#          скорость + движение
держу       :Me#  :Me#  :Me#    повтор каждые 200 мс (ARROWS_REPEAT_MS)
отпустил    :Qe#
```

## Зачем скорость перед каждым нажатием

Главный по скорости — пульт. Если монтировка перезагрузилась (у неё снова SLEW)
или скорость поменял Stellarium, первое нажатие всё равно поедет с той скоростью,
что на экране пульта.

## Зачем повтор

Монтировка (в будущем) остановит ось сама, если повтор не пришёл за ~500 мс.
Значит, при потере связи ось остановится не позже чем через полсекунды.

```
пульт:       :Me# ── :Me# ── :Me# ── ✕ связь пропала
монтировка:  едет    едет    едет    ... 500 мс без повтора → стоп
```

## Файлы

| Файл | Что внутри |
|---|---|
| `arrows.h` | API и `ARROWS_REPEAT_MS` |
| `arrows.cpp` | массив `held[4]` (зажата ли стрелка N/S/E/W) и время последней отправки |

## Функции

| Функция | Что делает |
|---|---|
| `arrows_press(dir, rate)` | `:R?#` + `:M?#`, отметить стрелку зажатой |
| `arrows_release(dir)` | `:Q?#`, если стрелка была зажата. `false` — не была, ничего не отправлено |
| `arrows_release_all()` | отпустить все зажатые (при открытии меню) |
| `arrows_forget_all()` | забыть все **без отправки**: после `:Q#` монтировка уже стоит |
| `arrows_is_held(dir)` / `arrows_any_held()` | для экрана (`Move: N E`) и для таймаута очереди |
| `arrows_repeat()` | если прошло 200 мс — повторить `:M?#` для зажатых |

## Как повтор встроен в задачу main_screen

Отдельного таймера нет. `task_main_screen` ждёт свою очередь с таймаутом:

```cpp
TickType_t wait = arrows_any_held() ? pdMS_TO_TICKS(ARROWS_REPEAT_MS) : portMAX_DELAY;
xQueueReceive(main_queue, &msg, wait);   // сообщение или таймаут
arrows_repeat();                         // сам проверит, прошло ли 200 мс
```

Пока стрелки не зажаты, задача спит без таймаута и процессор не тратит.

## Ограничения

- Только для задачи main_screen: вызывать только из неё, защиты от одновременного доступа нет.
- Команды уходят не напрямую, а в очередь `task_mount_link` (`mount_link_*`).
- ▲ и ▼ одновременно: монтировка останавливает **ось**, поэтому отпускание одной
  стрелки остановит ось, а повтор другой снова её запустит (TODO в info/menu.md).
