# mcp_device — расширитель портов MCP23017

## Какую задачу решает

Свободных ног у ESP32-C3 Super Mini мало, а кнопок 7. MCP23017 даёт 16 линий
ввода-вывода по двум проводам I²C. Модуль подключает чип к шине, настраивает
порт A под кнопки и читает их состояние.

```
ESP32-C3 ──I²C (адрес 0x20)──► MCP23017 ── GPA0..GPA6 ──► 7 кнопок ──► GND
         ◄──── INTA (GPIO3) ───┘
```

## Файлы

| Файл | Что внутри |
|---|---|
| `mcp_device.h` | адрес `0x20`, маска кнопок `0x7F`, API |
| `mcp_device.cpp` | адреса регистров, таблица настройки, запись с проверкой, чтение |

## Настройка (таблица `config[]` в `mcp_setup`)

| Регистр | Значение | Что значит |
|---|---|---|
| `IOCON` | `0x00` | INTA активный 0 (push-pull), адрес регистра растёт сам |
| `OLATA` / `OLATB` | `0x00` | выходы будут в 0 |
| `IODIRA` | `0x7F` | GPA0–6 — входы, GPA7 — выход (у этого чипа GPA7 только выход) |
| `IODIRB` | `0x00` | порт B не используется — все выходы, чтобы ноги не «висели» |
| `GPPUA` | `0x7F` | подтяжка 100 кОм к питанию: отпущена = 1 на ноге |
| `IPOLA` | `0x7F` | инверсия чтения: **нажата = 1** в программе |
| `INTCONA` | `0x00` | прерывание при **любом** изменении: и нажатие, и отпускание |
| `GPINTENA` | `0x7F` | прерывания разрешены на GPA0–6 |

После записи каждый регистр читается обратно и сравнивается. Если чип не
ответил или значение другое, в лог пишется ошибка с номером регистра.
В конце читается GPIOA: это сбрасывает прерывание, если оно успело возникнуть.

## Функции

| Функция | Что делает |
|---|---|
| `init_mcp(bus)` | добавить чип на шину (100 кГц) и вызвать `mcp_setup()` |
| `mcp_setup()` | записать и проверить таблицу настройки |
| `mcp_read_buttons(&buttons)` | прочитать GPIOA, оставить биты 0–6. Мьютекс берёт **вызывающий** |

## Важно про INTA

INTA держится в 0, **пока не прочитан GPIOA** (или INTCAPA). Если не прочитать,
следующие нажатия не дадут нового спада на GPIO3. Поэтому задача кнопок читает
GPIOA после каждого прерывания.

## Известные моменты

- `init_mcp()` пишет ошибки в лог, но всегда возвращает `ESP_OK`.
